# jackharvest/homebrew-tap

Homebrew formulae for my projects.

```sh
brew tap jackharvest/tap
```

## Formulae

### [bt820](https://github.com/jackharvest/bt820)

Print 4×6 shipping labels on the REKDOM BT820 thermal label printer from a Mac.

```sh
brew install jackharvest/tap/bt820
```

```sh
bt820print label.pdf     # print a label
bt820ctl start           # add BT820 to the macOS print dialog (⌘P)
```
